Colorizing the Prokudin-Gorskii photo collection

Before color photographs were captured, Sergei Mikhailovich Prokudin-Gorskii would capture photographs onto glass plates, using red, blue, and green filters to capture the different color 'channels' (as we refer to them now). His glass plate negatives captured the end of the Russian Empire, and they are now available online.

There are three versions of the same image, each showing one color channel of the image (the order of these filters is blue, green, red). This project takes those three color channels and merges them into one colorized photograph.


Single-scale alignment

The brute-force method is to take the three filters and overlap them where they align the most. When there is a corner on an image, the red, blue, and green filters will all reflect that sharp edge at similar intensities. With that motivation in mind, for each color pair, I found the alignment that would minimize the error between the two, and then merged those results into a final image.

To minimize the error, there were two methods to consider, Euclidean distance and normalized cross-correlation (NCC). I decided to go for NCC, which is a dot product between two mean subtracted normalized vectors. Raw Euclidean distance is sensitive to variations in image brightness between channels, but NCC subtracts the mean and normalizes vectors, so it is invariant to uniform brightness shifts across the plates. I used a for loop to iterate through a window (30 x 30 pixels) and pick the alignment that would minimize my error. This worked well on smaller images. Before calculating NCC, I cropped around 10% of the outer border margin, which prevents the dark outer glass frame from messing with the alignment score.


Multi-scale pyramid alignment

However, for high-resolution .tig images, this single-scale alignment method is an incredibly computationally expensive process. To speed up the process, I implemented a multi-scale pyramid alignment method using a recursive coarse to specific search.

The recursive pyramid starts by checking the resolution of the image channels. If it's around 300 x 300 pixels (the size of the smaller images on which brute-force worked), I call the brute-force align method to get a coarse displacement (which uses a default window of [-15, 15] for the error search). Otherwise, I halve the image (width and height) and recursively call the pyramid function on that downsized image.

As the recursion goes back up to higher resolutions, the method doubles the estimated displacement vector from the lower resolution level to account for the 2x scale. It applies the coarse shift I computed to pre-align the channel, and then does a fast error search using a tighter [-2, 2] pixel window for fine-tuning the alignment.



Images from the LOC archive

I tested the effectiveness of my pyramid alignment implementation on more high-resolution .tif plates from the Library of Congress Prokudin-Gorskii collection.


Failures

This alignment failed with my method. The red channel seems to be misaligned, as you can see the red overlay. This is likely because the emir's robes are a very vibrant blue, so they will register brightly on the blue channel: high pixel intensities. However, the red channel will register the robes as dark: very low intensities. So the intensity difference will not fare well via the error minimization method that I have been using for the other images' alignment thus far. There are other methods that can be used, like gradient maps (for example, Sobel edge detection), which would align structural edges instead of the raw color intensities.
