Auto-Stitching Photo Mosaics

This project, I learned about image mosaicking, how to combine overlapping photos so they transitioned to each other seamlessly, using techniques like nearest neighbors and bilinear interpolation. It was fun to flatten out pictures, and more enjoyable to construct panoramas and see how cool and effortless the result looks.

Part A.2: Recover Homographies

Next, I implemented homography recovery. To compute a homography matrix H, I established multiple (N) corresponding point pairs (x, y) -> (x', y'). Only 4 were needed but for better accuracy and results, I did quite a few. For each correspondence \((x,y)\rightarrow(x',y')\), I used the homography mapping equations to construct two rows of the linear system. Writing the homography matrix as

\[ H = \begin{bmatrix} h_1 & h_2 & h_3\\ h_4 & h_5 & h_6\\ h_7 & h_8 & 1 \end{bmatrix}, \]

the mapping from the point \((x,y)\) to \((x',y')\) gives

\[ x' = \frac{h_1x+h_2y+h_3}{h_7x+h_8y+1}, \qquad y' = \frac{h_4x+h_5y+h_6}{h_7x+h_8y+1}. \]

Rearranging these equations into linear form gives

\[ xh_1+yh_2+h_3-xx'h_7-yx'h_8=x', \] \[ xh_4+yh_5+h_6-xy'h_7-yy'h_8=y'. \]

These equations produce the two rows added to \(A\) and the corresponding entries added to \(\mathbf{b}\):

\[ \underbrace{ \begin{bmatrix} x & y & 1 & 0 & 0 & 0 & -xx' & -yx'\\ 0 & 0 & 0 & x & y & 1 & -xy' & -yy' \end{bmatrix} }_{\text{two rows of } A} \underbrace{ \begin{bmatrix} h_1\\h_2\\h_3\\h_4\\h_5\\h_6\\h_7\\h_8 \end{bmatrix} }_{\mathbf{h}} = \underbrace{ \begin{bmatrix} x'\\y' \end{bmatrix} }_{\text{corresponding entries of } \mathbf{b}}. \]

Repeating this process for all \(N\) correspondences produces a \(2N\times 8\) matrix \(A\) and a \(2N\times 1\) vector \(\mathbf{b}\). I then solve \(A\mathbf{h}\approx\mathbf{b}\) using linear least squares to estimate the eight unknown homography parameters.

The correspondences are shown on the image pairs. They are pretty faint (red dot maps to white square).

Part A.3: Warp the Images

I implemented inverse warping using both nearest neighbor and bilinear interpolation. First, I mapped the source image corners through H to compute the output bounding box and translation matrix. Then I used inverse mapping to map each destination pixel back to its corresponding location in the original image.

Nearest neighbor assigns each destination pixel that value of the closest source pixel. It's fast, but it can produce jaggies. Bilinear interpolation computes a weighted average of the four neighboring pixels, which is smoother, but slower. I have displayed my results here, bilinear is a bit crisper and sharper compared to nearest neighbors. It's more visible in the postcard, where you can see that the mountain is more define with bilinear.




Part A.4: Blend the Images into a Mosaic

Finally, I blended the images from parts 1 and 2 into an image mosaic.

For each image pair, I first computed the bounding box for both warped images by transforming the four corners of each image using its homography. Then I calculated a translation matrix to shift the bounding box so the entire mosaic fits within the output image. Next, I warped each image into the shared output coord system using bilinear interpolation. For each warped pixel, I calculated its distance from the nearest edge of the original image. Pixels closer to the center got larger weights, and near the edges got lower weights. Outside the image they were 0. Finally, I multiplied each warped pixel by its weight and accumulated the weighted pixel values and weights across both images. At each output pixel, I divided the accumulated weights by the total weight, which blends overlapping regions instead of causing overwriting.
