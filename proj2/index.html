Part 1: Fun with Filters

The brute-force method is to take the three filters and overlap them where they align the most. When there is a corner on an image, the red, blue, and green filters will all reflect that sharp edge at similar intensities. With that motivation in mind, for each color pair, I found the alignment that would minimize the error between the two, and then merged those results into a final image.

Part 1.1: Convolutions from Scratch

First I implemented convolution from scratch. It was pretty straightforward. I first flipped the kernel (horizontally and vertically) and padded the image. Padding is important because without it, the filter would extend past the boundaries of the image, and the output image would either shrink or not have the edges properly convolved. So I implemented zero padding at the boundaries, extending the image a bit. Then I slide the filter over the padded image; at each position /pixel, I computed the dot product between the image and filter overlap, and that is what I put in the resulting image's pixel.

Four for loops
def convolution(img, kernel):
    h, w = img.shape
    kh, kw = kernel.shape
    ph, pw = kh // 2, kw // 2
    padded = np.pad(img, ((ph, ph), (pw, pw)), mode='constant')

    flip = np.flip(kernel)
    rv = np.zeros((h, w))
    for i in range(h):
        for j in range(w):
            pixel = 0
            for x in range(kh):
                for y in range(kw):
                    pixel += flip[x, y] * padded[i + x, j + y]
            rv[i, j] = pixel

    return rv
Two for loops
def convolution(img, kernel):
    h, w = img.shape
    kh, kw = kernel.shape
    ph, pw = kh // 2, kw // 2
    padded = np.pad(img, ((ph, ph), (pw, pw)), mode='constant')

    flip = np.flip(kernel)
    rv = np.zeros((h, w))
    for i in range(h):
        for j in range(w):
            pixels = padded[i : i + kh, j : j + kw]
            rv[i, j] = np.sum(pixels * flip)

    return rv

Part 1.2: Finite Difference Operator

In this part, I convolved the image with finite difference operators, Dx and Dy. From that, I computed the gradient magnitude image, and then binarized that using a threshold. This threshold was meant to hide noise at a certain level while showing true edges. The threshold that I settled on was 0.20. Lower numbers had a lot of noise interspersed, while higher numbers caused a lot of details to be lost.


Part 1.3: Derivative of Gaussian (DoG) Filter

When we did the finite difference edge detection, there was a lot of noise. To deal with this, we first convolved the image with a 2D Gaussian filter (I chose the size to be 9x9, with sigma=1.5) to smooth out finer details and high frequencies a bit. Then, I applied the finite difference operators Dx and Dy to this blurred image to get smoothed partial derivatives. When I calculated the gradient magnitude on the smoothed image, the edge detection is a lot cleaner, and the threshold was a lot lower (0.06). So we got rid of noisy specks in the background, but kept the strong outlines of the main items in the scene.

What we also know is that blurring an image and then taking its derivative is equivalent to convolving the image with a single pre-computed filter, or Derivative of Gaussian (DoG) filters. I got the DoG filters by convolving the 2D Gaussian kernel with Dx and Dy. Instead of needing 2 sequential convolution steps, we can get the gradients in one pass, and then get the binarized edge map. They are both identical.

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

In this section, I worked on sharpening an image. We used something called unsharp masking, which sharpens an image by isolating its high frequency details and then amplifying those. Like we've talked about, high frequencies mark sharp changes in edges or textures. To actually capture the high frequencies of an image, first I convolved the original image with a Gaussian filter to get a blurred image, which are the low frequencies. Then, I solved for the high frequencies simply by subtracting the low frequencies from the original image. Then to actually sharpen the original image, I scaled and then added the high frequencies back to the original image using a scalar factor alpha. So I was able to sharpen the image by increasing contrast at edges/high frequencies/boundaries.

I tested various alpha values. Alpha ultimately represetns the strength of the sharpening. You can see that the image seems to get sharper and sharper the higher alpha is, but there eventually are ringing artifacts and more background grain/noise. It looks unseemly.

I also tried taking an already sharp image, blurring it with a Gaussian filter, and then trying to sharpen it again back to its original state. While the resulting image does look sharp, it is not the same as it originally was. By applying the Gaussian blur, we are losing information, and it is not possible to regain that when resharpening. Also, if you look closely, you can see ringing artifacts near the edges of the image.

I tried it (high res -> blur -> sharpen) on another high resolution image, but you can see the same thing happen.


Part 2.2: Hybrid Images

Based on the paper by Oliva, Torralba, and Schyns, I implemented hybrid images. Human perception processes images using different spatial frequencies depending on distance from the object. High spatial frequencies are more visible when looking close up, whereas low spatial frequencies dominate when looking from afar.

To create a hybrid image, first I had to align the two images. I picked keypoints from each as an anchor. For example, with the classic example of Derek and Nutmeg, I used their eyes as anchors/keypoints. Then, I applied a 2D Gaussian (low-pass) filter to the second image to extract low frequencies. To the first image, I subtracted its low-pass version from its original self, to retain high frequencies and edges. Then I summed those two outputs and clipped to a valid intensity range. When applying filters to the two iamges, I had to tune sigma values to see how much information I wanted to retain. I had to preserve enough detail of image 1 when looking up close, while still keeping enough information from image 2 so that you could make it out when looking from afar. Eventually I settled on sigma1 = 5, and sigma2 = 8.

I tried it on some other images as well, and plotted the frequencies too.

Part 2.3: Gaussian and Laplacian Stacks

In this part, I implemented Gaussian and Laplacian stacks. I implemented them from scratch, without downsampling (which loses information). Normal image pyramids downsample; instead, a stack maintains the original image dimensions across all levels.

A Gaussian stack is constructed by repeatedly applying a Gaussian filter to an image but with increasing sigma values (I doubled each time) without subsampling. The Laplacian stack is computed by taking the difference between adjacent levels of the Gaussian stack. The last level has the lowest frequency residual base.
